# Reproducing the results

Everything in the paper is regenerated by the scripts below. No author names appear in the code.

## Environment

- Python 3.12 with `numpy`, `matplotlib`, `Pillow`, `pqcrypto` (ML-KEM-768 and ML-DSA-65).
  Pin `fonttools==4.51.0`: newer builds fail to load the compiled `iup` extension in this runtime,
  which breaks the PDF backend of matplotlib.
- ProVerif 2.05.
- TeX Live 2025 (`pdflatex`, `latexmk`, `pdftotext`).
- Tested on Windows 11, single core.

If ProVerif is blocked by an application-control policy, run `proverif/enroll.pv` and
`proverif/enroll_compromised.pv` on a machine where it is allowed; the two `RESULT` lines are recorded in
`proverif/README.md`.

`pip install numpy matplotlib pillow pqcrypto` is enough for the Python side. If `pqcrypto` is absent,
`enroll.py` falls back to X25519 + a toy RSA and says so in its output; the paper's numbers assume the
`pqcrypto` backend.

## One pass

```
cd prototype
python veil_core.py        # self-test; prints 9760 / 9824 / 10896 and extraction results
python eval_full.py        # E1-E5 -> results/full.json
python probe_vs_t.py       # probe vs box width -> results/probe_vs_t.json
python cost_model.py       # per-operation costs and the predicted total
python dual_regev.py       # real CPA dual Regev; ciphertext 3075 B
python td_demo.py          # MP12 trapdoor; carrier 8426 B, 384/384 bits recovered
python cca_demo.py         # FO rejects the anamorphic ciphertext
python enroll.py           # ML-KEM-768 + ML-DSA-65 enrollment
python mcp_demo.py         # gateway / credential / direct topologies

cd ../proverif
proverif enroll.pv            # payload secrecy true, correspondence true
proverif enroll_compromised.pv  # payload secrecy false (negative control)

cd ../figures
python plot_results.py     # Figures 3-5 (PNG + PDF)
python make_figures.py     # draw.io sketches; the paper uses TikZ versions of Figures 1-2

cd ..
latexmk -pdf veil.tex
```

## Stand-ins and caveats

- The ring prototype appends a **1088-byte structural stand-in** for the anonymous carrier; the 12835-byte
  figure is the ring plus the separately measured 3075-byte ciphertext. `results/phase3.json` records 10896
  for the stand-in.
- `td_demo.py` uses `n=384`, `q=2^13` for mechanics; the factor 13.5 is in coefficients and 7.3 in bytes.
- `cca_demo.py` uses `n=256, m=1024, t=256`; it demonstrates rejection, not a security level.
- `mcp_demo.py` simulates the transport and the tool latency (120 ms per step); no language model is called.
- Parameters are mechanics-only; the paper makes no security-level claim.
